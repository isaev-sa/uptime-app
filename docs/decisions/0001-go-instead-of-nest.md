# 0001. Бэкенд на Go, а не на Nest.js

## Контекст
API для uptime-мониторинга. Ядро - параллельный опрес сотен эендпоинтов с таймаутами и планировщиком.

## Решение
Бэкенд на Go.

## Почему
- Конкурентность - родная: горутины, context, -race
- Один бинарник, мало памяти - дёшево хостить

## Отвергли
- Nest.js - конкурентность неудобна, а именно она тут ядро
